# Manual del vendedor — Inventario Naty

Una hoja para tener en el mostrador. Todo se hace desde el navegador (computadora o celular).

## 1. Empezar el día
1. Ingrese con su **usuario y contraseña** (no importan las mayúsculas en el usuario). Si olvidó la clave, avise a la administradora: ella le asigna una temporal desde *Usuarios* y el sistema le pedirá elegir una propia al ingresar.
2. Entra directo al **punto de venta** (menú *Ventas*).
3. Si aparece **“No hay una caja abierta”**, escriba el efectivo con el que empieza el turno en *Efectivo en caja al abrir (Bs)* y toque **Abrir caja**. Sin caja abierta no se puede vender.

## Cambiar mi contraseña
Toque su nombre en el menú (**Cambiar contraseña**). Escriba la contraseña actual, la nueva (12 o más caracteres, distinta de la actual) y repítala. Una frase de palabras separadas por guiones es fácil de recordar. Al cambiarla, las sesiones abiertas en otros aparatos se cierran. Si se equivoca varias veces con la contraseña actual, el sistema espera unos minutos antes de dejarla intentar de nuevo.

## 2. Vender
1. El cursor ya está en la barra *Escanear o buscar producto*. **Escanee** la etiqueta del producto con el lector, con la cámara (botón *Escanear*) o escriba modelo, color y talla y elija con Enter.
2. Cada producto escaneado entra al carrito. Si escanea el mismo otra vez, sube la cantidad. Si no hay stock suficiente, el sistema se lo avisa.
3. **Descuento:** cambie el *Precio final* de la línea. Si es menor al mínimo permitido, el sistema muestra el mínimo y no deja confirmar.
4. **Cliente (opcional):** busque uno o toque *Nuevo cliente* (nombre, teléfono, CI/NIT).
5. Elija **Factura** o **Nota de venta**.
6. **Pago:** por defecto todo en efectivo. Para pagar mitad efectivo y mitad QR: escriba el monto del pago 1, toque **+ Agregar otro pago** y **Completar el pago 2**. La suma de los pagos debe ser igual al total (“Pagos completos”). En efectivo puede escribir cuánto le dieron para ver el cambio.
7. Toque **Confirmar venta** (o **Ctrl + Enter**). Se abre el **ticket**: imprímalo con *Imprimir*.

Atajos: **F2** o **/** vuelven a la barra de búsqueda. Todo el punto de venta funciona solo con teclado.

## 3. Cambio de talla o de modelo
1. *Ventas → Historial*, abra la venta y toque **Registrar un cambio**.
2. Marque el par que devuelve el cliente y busque el par nuevo.
3. Si el nuevo cuesta más, el sistema calcula la diferencia: elija cómo la paga el cliente. Si cuesta menos, el sistema calcula lo que se devuelve y le pide el método de devolución.
4. Elija el motivo y **Confirmar el cambio**. El stock se mueve solo y se imprime el comprobante.

Las ventas **no se borran**. Si se equivocó, avise a Naty: ella puede **anular** la venta.

## 4. Cerrar la caja
1. Menú *Ventas → Caja*, cuente el efectivo del cajón.
2. Escriba el monto en *Efectivo contado (Bs)* y toque **Cerrar caja**.
3. El sistema muestra lo esperado, lo contado y la diferencia. Cierre su turno antes de irse.

## 5. Consultar stock y ver sus ventas
- **Stock:** lista de pares de su sucursal con color, talla y estado (verde disponible, ámbar pocos, rojo agotado).
- **Reportes → Mis ventas:** hoy, semana, mes o un rango. **Descargar Excel** baja el mismo reporte en una planilla.

## 6. Errores comunes
| Mensaje | Qué hacer |
|---|---|
| **No hay una caja abierta** | Abra la caja con el monto inicial (paso 1.3). |
| **Falta cobrar Bs …** | Los pagos no llegan al total: complete el pago o agregue otro. |
| **Los pagos superan el total** | Baje algún monto de pago. |
| **Solo hay N de … / sin stock** | No quedan pares suficientes: busque otra talla o avise a Naty. |
| **El precio mínimo es Bs …** | El descuento es mayor al permitido: suba el precio o pida autorización a Naty. |
| **Usuario o contraseña incorrectos** | Revise mayúsculas. Después de varios intentos el acceso se bloquea unos minutos. |
| **No se pudo conectar con el sistema** | Revise internet y reintente. Si sigue, avise a Naty. |
| Pantalla de ingreso de pronto | Su sesión terminó: vuelva a ingresar. |

## Pedidos web (tienda online)
*Pedidos web* muestra los pedidos de su sucursal (la insignia cuenta los confirmados por despachar). Abra uno para ver qué preparar, a quién y a dónde. Puede marcar **en camino**, **listo para recoger** y **entregado** (si el cliente paga al recibir, elija cómo pagó). No confirma pagos, no cancela y no ve comprobantes ni los ajustes de la tienda; tampoco ve costos.
